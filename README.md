# 车载语音路由实验台

中文文本原型，用来从一段文本中逐句筛选出需要交给 Agent 的句子，并比较候选模型。模拟模式默认可用；真实 API 模式需要供应商密钥。

## 启动

需要 Python 3.9 或更新版本，不需要安装第三方包。

```bash
cd /path/to/agent-router-demo
python3 server.py
```

打开终端打印的本地地址，默认是 <http://localhost:8765>。按 `Ctrl+C` 停止服务。

## 模拟模式

模拟模式按句号、问号、叹号、分号和换行分句，再用页面中的本地规则逐句给出基线结果；逗号不切句。它不会调用 Qwen、DeepSeek、GLM 或 Kimi，也不代表这些模型的能力。真实 API 模式要求模型先对文本分句，再逐句输出路由判定。样例集的召回率和误转率按句计算，仅用于验证交互，不应作为模型评测结论。

## 真实 API 模式

API 密钥由本机服务端从环境变量读取，不会保存到浏览器或项目文件。设置需要测试的平台密钥后启动服务，例如：

```bash
export QWEN_API_KEY='...'
export DEEPSEEK_API_KEY='...'
export GLM_API_KEY='...'
export KIMI_API_KEY='...'
python3 server.py
```

只需设置正在测试的平台变量。默认 API model ID 参考 2026-10-20 可见的官方文档：`qwen-flash`、`deepseek-flash`、`glm-5.3-flash`、`kimi-k3`。也可以通过 `QWEN_MODEL`、`DEEPSEEK_MODEL`、`GLM_MODEL`、`KIMI_MODEL` 环境变量覆盖。供应商可能会调整 SKU、endpoint、地区和账号权限，真实实验前请以账号控制台及官方文档为准。

真实调用会把输入话术发往所选供应商。避免使用含个人信息或敏感车内录音内容的文本，除非已确认对应平台的数据处理条款。

## 路由定义

- 处理单位是句子，而不是整段文本。含有多句时，各句独立判断，只汇总需要转交的原句。
- 需要 Agent：需要车辆/导航/媒体工具执行、信息查询、开放域回答、多轮指代或组合意图的句子。
- 不需要 Agent：寒暄、确认/感谢、明显噪声转写或无法形成意图的残句。
- 置信度阈值、能力和风险用于原型观察。模型自报置信度没有统计校准；高风险或复杂意图在级联模拟中强制升级。

样例标签应由产品、语音和 Agent 团队按目标系统的路由边界共同确认。该原型不是车端部署、功能安全或量产性能验证。
